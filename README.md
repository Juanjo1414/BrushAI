# BrushAI

Aplicación móvil con **IA de visión por computadora** y **gamificación** para ayudar a los niños a crear el hábito de cepillarse los dientes correctamente.

* Niño: escanea sus dientes y recibe retroalimentación motivacional.
* Padre/Acudiente: supervisa historial, estadísticas y recibe alertas.
* (Fase 2) Visualización en **AR** para guiar la técnica de cepillado.

---

## 🚀 Características

* **Registro/Login** con perfiles de niño y padre.
* **Escaneo con IA** para evaluar calidad del cepillado.
* **Retroalimentación y gamificación** (misiones, rachas, recompensas).
* **Panel parental** para historial y estadísticas.
* **Notificaciones push** (recordatorios y alertas).
* **Suscripción Premium** (fase 2).
* **Visualización AR** (fase 2).
